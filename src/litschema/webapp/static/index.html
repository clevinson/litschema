Filter expression reference

The filter is a JavaScript boolean expression evaluated against each article's record. Combine fields with &&, ||, and comparisons like ===, !=, <, >=. Arrays support .includes(...), .some(...), and .length.

Deep extraction fields (e.g. experimental_setups, quantification_approaches, modeling_details) load in the background when this panel opens. Until they finish loading, expressions that reference them will return no matches; the count will update automatically once load completes.
