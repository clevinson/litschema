    Reviewer identity

    Optional. Connect an ORCID to record who reviewed each field. Reviews save without one.

    Project policy

    Saved to litschema.yaml and enforced when reviews are saved, so it applies to everyone auditing extractions in this project — not only people working on this computer.

    Filter expression reference

    The filter is a JavaScript boolean expression evaluated against each article's record. Combine fields with &&, ||, and comparisons like ===, !=, <, >=. Arrays support .includes(...), .some(...), and .length.

    Deep extraction fields (e.g. experimental_setups, quantification_approaches, modeling_details) load in the background once you start writing an expression. Until they finish loading, expressions that reference them will return no matches; the count will update automatically once load completes.
